# 05 — Python Project for Data Science

✅ **Status:** Completed

## Overview

This course focused on extracting real-world data through **web scraping** and **APIs**, then using it to build a data visualization dashboard — the core end-to-end workflow of a data science project: *collect → clean → analyze → visualize*.

## 📓 Notebooks

| Notebook | Description |
|---|---|
| [`01_web_scraping_lab.ipynb`](notebooks/01_web_scraping_lab.ipynb) | Practice lab on extracting structured data from HTML pages using `requests` and `BeautifulSoup`. |
| [`02_stock_revenue_dashboard_final_project.ipynb`](notebooks/02_stock_revenue_dashboard_final_project.ipynb) | **Final graded project.** Extracts Tesla and GameStop stock data via the `yfinance` API and quarterly revenue data via web scraping, then visualizes stock price against revenue trends using `plotly`. |

## 🎯 What This Project Demonstrates

- Fetching financial time-series data through an API (`yfinance`)
- Scraping and parsing HTML tables for revenue data
- Cleaning and merging data with `pandas`
- Building interactive dual-axis visualizations with `plotly`

## 🛠 Tools

`Python` · `pandas` · `yfinance` · `BeautifulSoup` · `requests` · `plotly`
