# 06 — Databases and SQL for Data Science with Python

✅ **Status:** Completed

## Overview

This course covered relational databases and SQL fundamentals — writing queries, joining tables, and connecting SQL databases to Python using `ipython-sql` and `sqlite3` — applied to real civic open data from the **City of Chicago Data Portal**.

## 📓 Notebooks

| Notebook | Description |
|---|---|
| [`01_chicago_data_graded_assignment.ipynb`](notebooks/02_chicago_data_graded_assignment.ipynb) | **Graded assignment.** Loads three linked Chicago datasets (Census socioeconomic indicators, Public Schools, and Crime data) into SQLite and answers analytical questions using SQL joins and aggregations. |

## 🎯 What This Project Demonstrates

- Loading CSV data into a SQLite database with `pandas.to_sql()`
- Writing SQL queries (filtering, aggregation, `JOIN`s) via `%sql` magic in Jupyter
- Combining multiple real-world civic datasets to answer analytical questions
- Working with the Chicago Open Data Portal as a real-world data source

## 🛠 Tools

`Python` · `SQLite` · `ipython-sql` · `pandas` · `Jupyter`
